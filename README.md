# daymew-privacy

今日喵力（DayMew）的隐私政策页面，可用 GitHub Pages 发布。

- `index.html`：隐私政策页面。打开后默认显示中文，顶部可切换到 English。
- `support/index.html`：支持页面，发布后地址为 `/support/`。同样默认中文，顶部可切换到 English。
- `DayMew-Privacy-Policy-zh-CN.md`：中文政策原文。
- `DayMew-Privacy-Policy-en.md`：英文政策原文。

本地预览：用浏览器直接打开 `index.html` 或 `support/index.html`。
